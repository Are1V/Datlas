# A/B experiment analysis

Simulate randomized control and treatment groups, estimate an effect, and report uncertainty.

## Project brief

- **Dataset:** [Synthetic experiment data](https://numpy.org/doc/stable/reference/random/generator.html)
- **Prerequisites:** Chapter 07, Chapter 28
- **Deliverable:** A notebook with a predefined metric, confidence interval, and decision.

## Objectives

- Set a random seed
- Compare effect size and uncertainty
- Explain practical significance

## Evaluation

Another learner can reproduce the result and explain its assumptions.

## Suggested repository structure

```text
README.md
requirements.txt
src/
tests/
notebooks/
```

## Start here

1. Create the folders shown above.
2. Record the dataset source and license in `data/README.md`.
3. Build the simplest defensible baseline first.
4. Keep validation data separate from model decisions.
5. Report errors, assumptions, and limitations with the final result.
