# Python mini project

Read a small CSV and summarize missing values, unique categories, and numeric ranges.

## Project brief

- **Dataset:** [Palmer Penguins](https://allisonhorst.github.io/palmerpenguins/)
- **Prerequisites:** Chapter 01
- **Deliverable:** A command-line CSV summary tool with tests.

## Objectives

- Read a file safely
- Use functions and dictionaries
- Test missing and invalid input

## Evaluation

Another learner can reproduce the result and explain its assumptions.
