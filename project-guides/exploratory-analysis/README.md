# A field guide to penguins

Explore how body measurements vary across penguin species and islands.

## Project brief

- **Dataset:** [Palmer penguins](https://raw.githubusercontent.com/mwaskom/seaborn-data/master/penguins.csv)
- **Prerequisites:** Chapter 07, Chapter 08, Chapter 11
- **Deliverable:** A question-led EDA report with five annotated figures.

## Objectives

- Ask analysis questions
- Visualize distributions
- Compare segments

## Evaluation

Check sample sizes, missingness, and units; distinguish association from explanation.
