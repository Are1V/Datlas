# Titanic survival analysis

Separate patterns in passenger survival from claims about causation.

## Project brief

- **Dataset:** [Titanic passengers](https://raw.githubusercontent.com/mwaskom/seaborn-data/master/titanic.csv)
- **Prerequisites:** Chapter 01, Chapter 07, Chapter 08, Chapter 10, Chapter 11
- **Deliverable:** An illustrated notebook and a one-page findings report.

## Objectives

- Explore distributions
- Handle missing observations
- Communicate uncertainty

## Evaluation

Validate denominators, show missingness, and report survival rates with uncertainty.
