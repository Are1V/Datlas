# SQL sales analysis

Explain revenue patterns and repeat purchasing for an online retailer.

## Project brief

- **Dataset:** [Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail)
- **Prerequisites:** Chapter 08, Chapter 09
- **Deliverable:** A SQL schema, validated queries, and a revenue dashboard.

## Objectives

- Join tables safely
- Write window functions
- Define business metrics

## Evaluation

Handle returns and null customer IDs; independently reconcile monthly totals.
